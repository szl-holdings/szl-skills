# Provenance

`scripts/pack.py`, `assets/pack-*.json`, the pack documentation and `tests/test_capsule_pack.py`
are an original Apache-2.0 SZL contribution (2026-10-06, base commit `b8e259c`). The ZIP approach
follows the repository's `tools/package_science.py`, which is not imported. `kernel.py` and its
workbench mirror are unchanged. No third-party code or data was copied; fixtures hash only
`assets/protocol.txt`.

# Computational control contract

Call `szl_audit_negative_controls(payload)` or `python scripts/run.py input.json`. The CLI exits 0 for CONTROLS_CONSISTENT_ON_SUPPLIED_EVIDENCE, 1 for INCONCLUSIVE, and 2 for invalid input. `--output` creates a new file exclusively. JSON must be UTF-8, at most 1 MiB and nesting depth 32, with no duplicate keys or nonfinite constants. Unknown fields are rejected.

The top object has exactly `schema` (szl.negative-control-audit.v1), `registry`, `artifacts`, `results`. The registry has `id`, integer `version`, `scope` COMPUTATIONAL, `frozen_at` UTC time, `graph`, `main`, `protocol_artifact`, `scorer_artifact`, `execution_artifact`, `controls`. UTC values use YYYY-MM-DDTHH:MM:SSZ. Identifiers use 1–128 letters, digits, period, underscore or hyphen, beginning with a letter or digit. Every artifact reference names a supplied artifact.

The graph has `nodes` (2–128 unique identifiers) and `edges` (at most 1024 unique two-element [parent, child] lists). It must be acyclic with no dangling/self edges. Main has distinct graph-node `intervention` and `readout`; a directed main mechanism path must be declared. Edges assert the scientist's mechanism assumptions, not observed causality.

Each of 1–32 controls has exactly `id`, `kind` (NEGATIVE_EXPOSURE, NEGATIVE_OUTCOME or SHAM_COMPUTATION), graph-node `intervention`, graph-node `readout`, `shared_nuisance` (1–32 unique graph nodes), nonempty `rationale` (at most 2048 characters), `input_artifact`, `metric` identifier, `expectation` ABS_DELTA_LE, and nonnegative finite `tolerance` at most 1e12. A negative exposure retains the main readout; a negative outcome retains the main intervention. No directed control-intervention/readout path may exist. Each nuisance must be a strict ancestor of both main endpoints and both control endpoints; a shared readout alone does not establish shared nuisance exposure. This deliberately supports controls declared to share those nuisance mechanisms. Other relevance assumptions require a different explicit contract. The shared-ancestor check validates the declared relation, not confounding completeness or test power.

Each of 1–64 artifacts has exactly `id`, `sha256` (64 lowercase hex characters) and `content_utf8`. The helper computes SHA-256 from exact UTF-8 bytes, including whitespace/newlines. Each artifact is at most 65536 bytes; their combined bytes are at most 1 MiB. Protocol, scorer and execution artifact content is inert data. The fixed execution artifact represents the declared execution environment/specification, not independently measured execution. No file path is followed and no code is run.

Each result reference has `control_id` and `outcome_artifact`. At most 32 results are accepted, with unique control ids. An outcome artifact's content is JSON with exactly:

- `schema`: szl.negative-control-result.v1; `control_id`; `metric`.
- `registry_sha256`: SHA-256 of canonical registry JSON (`json.dumps` sorted keys, separators comma/colon, ensure_ascii false, UTF-8, no NaN). `canonical_sha256` provides this calculation. `protocol_sha256`, `scorer_sha256`, `execution_sha256`, `input_sha256`: hashes matching actual referenced supplied bytes.
- `tolerance`: planned tolerance, exactly unchanged; `delta`: finite signed supplied null-effect estimate bounded by ±1e12 for SUCCESS, otherwise null. The check is absolute delta <= planned tolerance, inclusive of the boundary.
- `started_at`, `completed_at`: declared UTC times, start at or after registry freeze, completion at or after start. These are not trusted timestamps.
- `status`: SUCCESS, FAILED or ABORTED; `failure_reason`: null for success, bounded nonempty text otherwise; `contaminated`: Boolean declaration.

Supply the signed delta from the experiment's fixed metric and comparator; the helper validates the supplied number and byte binding but cannot recompute a scientific estimator from missing raw measurements. A failed result remains in the report and cannot be turned into a numeric estimate.

Output has schema szl.negative-control-audit-report.v1, status, canonical registry hash, deterministically sorted findings, each parsed control's outcome hash/status/delta, and each artifact's actual/declared digest and MATCH/MISMATCH. All findings make the result INCONCLUSIVE, including missing or unregistered controls, absent bytes, graph expectation conflicts, changed protocol/scorer/execution/input, different identity/metric/tolerance, timing conflicts, contaminated or failed controls, and absolute null failure. Malformed input raises ValueError/CLI INVALID_INPUT rather than producing a partial clean report. Preregistration remains DECLARED_ONLY, mechanism validity DECLARED_GRAPH_ONLY and scientific performance NOT_MEASURED.

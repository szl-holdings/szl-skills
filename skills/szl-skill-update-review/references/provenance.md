# Provenance and scope

This package is original code under the repository's Apache-2.0 license. The design inspected the local `szl-skills` source at commit `b36160ea1d6b375670ea662cff6a2cc67cba0f40`, especially its reproducibility-capsule path and byte-integrity checks, repo-pin revision record, and research-anatomy dependency notes. No source code was copied from those packages or from the separately inspected MIT-licensed community skill checker. The new helper is standalone so packaging it does not import sibling skills.

The review uses only caller-supplied local data. Pinning and hashing are integrity checks against the retained lock, not provenance authentication, behavior analysis, code safety, license verification or scientific validation.

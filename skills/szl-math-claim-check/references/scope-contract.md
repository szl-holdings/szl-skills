# Scope contract

`szl_audit_math_scope(contract)` accepts `szl.math-claim-scope.v1`. All inputs are
caller-supplied observations, not executable instructions. The CLI detects this schema;
legacy numerical payloads retain their existing API. Invalid types, duplicate assumptions,
non-finite numbers, empty/reversed intervals and oversized fields raise `ValueError`.
Top-level JSON must fit 8 MiB; strings fit 65,536 characters, identifiers 256 characters,
assumption/axiom lists 256 entries and domains 64 variables. CLI rejects duplicate JSON keys.

Required objects:

| Object | Required fields |
| --- | --- |
| `claim` | `statement` (exact UTF-8 text), `relation` |
| `theorem` | `symbol`, `proposition` (exact supplied text), `relation`, `assumptions`, `domain`, `source_sha256`, `toolchain_sha256`, `dependency_lock_sha256` |
| `runtime` | `relation`, `assumptions`, `domain`, `source_sha256`, `numeric_semantics` |
| `observed_artifacts` | Observed `formal_source`, `runtime_source`, `toolchain`, `dependency_lock` hashes; omissions yield UNKNOWN |
| `allowed_axioms` | Explicitly reviewed transitive axiom names; defaults to empty |
| `proof_record` | `theorem_symbol`, `proposition_sha256`, `source_sha256`, `toolchain_sha256`, `dependency_lock_sha256`, retained `log`, `log_sha256`, integer `exit_code`, boolean `contains_sorry`/`contains_admit`, `transitive_axioms`, `custom_axioms`; omission yields UNKNOWN |
| `correspondence` | `statement_sha256`, `proposition_sha256`, `runtime_source_sha256`, `reviewer`, `evidence_sha256`, `informal_to_formal`, `formal_to_runtime`, boolean `numeric_semantics_reviewed`; omission yields UNKNOWN |

All hashes are lowercase SHA-256. Text hashes cover exact UTF-8 bytes, without newline
normalization. Observe source, toolchain and lock bytes externally using the user's selected
artifacts; label absent readbacks UNKNOWN rather than manufacturing a match. `log_sha256`
binds the supplied log text. Metadata describing the checker observations does not prove that
the log was generated by the named compiler. Inspect retained logs and pin provenance before
entering these observations; a string search cannot establish complete transitive axioms.

Relations are `equal`, `le`, `ge`, `implies`, `iff`; declared claim and runtime relations must
match the theorem. This deliberately requires review of direction and does not infer logical
equivalence from theorem text. Numeric semantics are `integer`, `rational`, `binary64`,
`symbolic`. Binary64 needs explicit recorded numeric-boundary review; this does not verify
overflow, conditioning, implementation correctness or a floating-point error bound.

Domains map names to `{lower, upper, lower_inclusive, upper_inclusive}`. Endpoints are finite
numbers or `null` for an unbounded endpoint; unbounded endpoints must be exclusive. Runtime
variables must exactly match theorem variables and each runtime interval must be a subset,
including boundary inclusion. Required theorem assumptions must occur in runtime assumptions.
Arbitrary predicates, quantified structures, implicit units and predicate implications need
human review beyond this interval check.

Correspondence states are `REVIEWED` or `NOT_REVIEWED`. Hashes bind the exact claim,
proposition and implementation to the review record; the evidence itself is not authenticated
or semantically inspected by this helper. Do not relabel an informal result as formally proven
because the record is internally consistent.

Output schema `szl.math-claim-scope-report.v1` contains sorted typed `findings`, supplied
log/statement/proposition/input hashes, `execution_authority: none`, `authentic: false`,
`proof_discharged: false` and `scientific_evaluation: NOT_MEASURED`. Status priority is BLOCKED,
then UNKNOWN, then STRUCTURAL_CHECKS_PASSED. Failure exit observations, binding mismatch,
unfinished proof observations, any custom axiom or unreviewed transitive axiom block. Missing
observations and reviews stay unknown. CLI exit zero means a report was produced, so inspect
its status before drawing conclusions.

`assets/scope-example.json` is a complete synthetic record, not an actual theorem checker run.
The acceptance suite tests success plus wrong symbol/proposition, custom axioms, missing log,
forged digest, failed checker, one-way-as-iff, scope extension, omitted assumption, floating
point boundary, stale correspondence and typed/bounded malformed input.

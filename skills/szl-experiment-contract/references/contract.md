# Input and output contract

Call `szl_draft_experiment_contract(payload)` or `python scripts/run.py input.json`. Python 3.9+, standard library, offline. JSON is UTF-8, at most 128 KiB and depth 16; duplicate keys, nonfinite constants, unsupported fields and invalid Unicode are rejected. `--output` creates a new file and refuses overwrite. Exit codes: 0 `DRAFT_READY_FOR_REVIEW`, 1 `NEEDS_RESEARCHER_INPUT`, 2 `INVALID_INPUT`.

Input schema `szl.experiment-contract.input/v1` has exactly `schema`, `study_id`, `fields`, `assumptions`, `source_ids`. `study_id` is a 1–128-character identifier. `fields` has exactly the keys shown in `assets/example.json`, each bounded nonempty text or null. `direction` is `HIGHER`, `LOWER` or null. Null means **unknown**, not a placeholder the helper may infer. `assumptions` has at most 16 unique-id objects with exactly `id`, `statement`, `check`; `check` may be null. `source_ids` has at most 16 unique nonempty text entries; they are declarations, not verified citations.

The helper asks about every null design field except `dependence_plan` when the three units are declared identical. A missing assumption or null assumption check also requires researcher input. If the independent, allocation and analysis units differ, `dependence_plan` is required and its presence is reported only as a declaration; no independence or model assumption is verified. If any of the three units is unknown, the unit relationship remains incomplete.

The output includes a canonical input SHA-256, normalized design, review questions, declared source IDs, and an `analysis_plan_handoff`. This handoff names plausible metric, direction and estimand fields; it maps sample/group units only when all three supplied unit names match, and even then requires researcher confirmation. It is **never** a frozen plan. The frozen-plan auditor also needs a freeze time, split digest, alpha and family, practical margin, exclusions, stopping rule and scheduled attempts. Output always says `NOT_REGISTERED`, `NOT_PERFORMED` for execution and inference, and `NOT_EVALUATED` for scientific efficacy. A complete draft means only that required declarations are present; wording plausibility, ethics, power, measurement validity and source authenticity remain open.

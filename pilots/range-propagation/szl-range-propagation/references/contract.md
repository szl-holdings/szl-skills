# Contract: szl.range-propagation.v1

The top-level JSON object has exactly `schema`, `inputs`, `steps`, `claims`. Unknown or duplicate keys are refused. The UTF-8 input is at most 1,000,000 bytes. Every list is nonempty and has at most 64 entries. IDs match `[A-Za-z][A-Za-z0-9_-]{0,63}` and are unique across inputs and steps. Claims name distinct step IDs.

Each input has exactly `id`, `unit`, `lower`, `upper`. The unit is one of the exact case-sensitive symbols from `szl-unit-invariants`: `1`, `m`, `cm`, `mm`, `km`, `kg`, `g`, `mg`, `s`, `ms`, `min`, `h`, `A`, `K`, `mol`, `cd`, `Hz`, `m/s`, `cm/s`, `m/s^2`, `N`, `Pa`, `J`, `W`. The SI dimension vector orders length, mass, time, electric current, thermodynamic temperature, amount of substance, luminous intensity. Every number is a string or JSON number in plain decimal form with at most 15 integer digits and 12 fractional digits. Exponents, non-finite values, booleans, and inverted ranges are refused. Inputs are multiplied by exact rational unit scales, not rounded binary floats.

Each step has exactly `id`, `operation`, `operands`. Operations are `sum`, `difference`, `product`, `ratio`; each has exactly two named operands. References must name previously declared inputs or steps, so future references and cycles fail closed. Addition and subtraction require identical dimension vectors. Multiplication adds and division subtracts exponents; each resulting exponent must stay in -16..16. A divisor interval containing zero yields `UNKNOWN`, with no claims certified. Graph depth is at most 32 and each rational numerator/denominator at most 512 bits.

Each claim has exactly `id`, `dimension`, `lower_si`, `upper_si`. The dimension is seven integer exponents in -16..16. Bounds are inclusive and already in canonical SI units. A claim passes only if its dimension matches and its interval contains the entire computed interval. Results and claims are reported as exact integer or `numerator/denominator` strings. Repeated operands remain conservative: `x - x` does not use shared-variable cancellation. `PASS_DECLARED_BOUNDS` applies only to these caller-supplied bounds under the declared input intervals. `FAIL_DECLARED_BOUNDS`, `UNKNOWN`, and `INVALID_INPUT` do not authorize a scientific conclusion.

The CLI reads at most 1,000,001 bytes, rejects duplicate JSON keys and malformed numeric tokens, and reports `input_bytes_sha256` for the exact bytes it read. `--output` creates exclusively and never replaces an existing file. Diagnostic codes contain no input text. Kernel `audit(record)` accepts plain dictionaries with decimal strings, Python integers, or `Decimal` endpoints; Python floats are refused because their original decimal lexemes are lost. The kernel performs no I/O or code execution.
